---
title: "WinterJS2.version"
slug: WinterJS2/version
---

The **`WinterJS2.version`** property holds the current winterjs2 version string
(CalVer `YY.MM.DD`, e.g. `"26.9.27"`). Assigning a string overrides it for the
rest of the session.

## Syntax

```js
WinterJS2.version
```

### Parameters

- `version`
  - : The version string.
