The **`WinterJS.graph`** property provides graph utilities (petgraph backend, id-heap like manual memory): `create`, `addNode`, `addEdge`, `toposort`, `counts`, `free`.

## Syntax

```js
WinterJS.graph.toposort(g)
```

### Parameters

- `id`
  - : The graph id.
