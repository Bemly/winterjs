slug: WinterJS2/graph

The **`WinterJS2.graph`** property provides graph utilities (manual id heap, like manual memory): `create`, `addNode`, `addEdge`, `toposort`, `counts`, `free`.

## Syntax

```js
WinterJS2.graph.toposort(g)
```

### Parameters

- `id`
  - : The graph id.
