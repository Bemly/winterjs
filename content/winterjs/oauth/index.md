slug: WinterJS/oauth

The **`WinterJS.oauth`** property provides OAuth2 helpers (URL building plus PKCE; token exchange uses fetch): `authorizeUrl`, `pkce`, `exchangeCode`, `refreshToken`.

## Syntax

```js
WinterJS.oauth.pkce()
```

### Parameters

- `options`
  - : See `authorizeUrl`/`exchangeCode` shapes.
