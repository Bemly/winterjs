title: "WinterJS2.oauth"
slug: WinterJS2/oauth
---

The **`WinterJS2.oauth`** property provides OAuth2 helpers (URL building plus PKCE; token exchange uses fetch): `authorizeUrl`, `pkce`, `exchangeCode`, `refreshToken`.

## Syntax

```js
WinterJS2.oauth.pkce()
```

### Parameters

- `options`
  - : See `authorizeUrl`/`exchangeCode` shapes.
