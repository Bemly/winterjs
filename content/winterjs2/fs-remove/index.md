title: "WinterJS2.fs.remove"
slug: WinterJS2/fs-remove
---

The **`WinterJS2.fs.remove(path, opts?)`** method removes a file or directory; directories need `opts.recursive`. Same object as global `fs.remove`.

## Syntax

```js
await WinterJS2.fs.remove(path, opts?)
```

### Parameters

- `opts`
  - : Optional `{ recursive }`.
