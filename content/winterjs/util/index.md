The **`WinterJS.util`** property provides `format` and `inspect` over the
same ported implementation node:util rides (Deno/Bun-namespace reuse pattern).

## Syntax

```js
WinterJS.util.format("%s=%d", "a", 1)
```

### Parameters

- `args`
  - : Format string followed by values.
