The **`WinterJS.transpile`** property provides the same oxc pipeline the loader runs: `transpile` turns TS-flavored source into JS.

## Syntax

```js
WinterJS.transpile("const x: number = 1;")
```

### Parameters

- `src`
  - : The source text.
