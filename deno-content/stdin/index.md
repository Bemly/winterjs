A reference to stdin which can be used to read directly from stdin.
It implements the Deno specific https://jsr.io/@std/io/doc/types/~/Reader | Reader, https://jsr.io/@std/io/doc/types/~/ReaderSync | ReaderSync, and https://jsr.io/@std/io/doc/types/~/Closer | Closer interfaces as well as provides a ReadableStream interface.
