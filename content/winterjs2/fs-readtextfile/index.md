slug: WinterJS2/fs-readTextFile
---

The **`WinterJS2.fs.readTextFile(path)`** method reads the entire contents of a file as a UTF-8 string. Same object as global `fs.readTextFile`.

## Syntax

```js
await WinterJS2.fs.readTextFile(path)
```

### Parameters

- `path`
  - : A non-empty string path.
