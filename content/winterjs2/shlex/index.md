The **`WinterJS2.shlex`** property provides Shell-lexing utilities: `split` cuts a command line into argv; unbalanced quotes throw.

## Syntax

```js
WinterJS2.shlex.split("a 'b c'")
```

### Parameters

- `text`
  - : The command line to split.
