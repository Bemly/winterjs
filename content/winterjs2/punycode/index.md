The **`WinterJS2.punycode`** property is the punycode core shared with
node:punycode (no DEP0040 here): `decode/encode/toASCII/toUnicode/ucs2`.

## Syntax

```js
WinterJS2.punycode.toASCII("münchen.de")
```

### Parameters

- `domain`
  - : The domain name to convert.
