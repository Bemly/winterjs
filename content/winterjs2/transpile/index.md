title: "WinterJS2.transpile"
slug: WinterJS2/transpile
---

The **`WinterJS2.transpile`** property provides the same transpiler the file loader runs: `transpile` turns TS-flavored source into JS.

## Syntax

```js
WinterJS2.transpile("const x: number = 1;")
```

### Parameters

- `src`
  - : The source text.
