slug: WinterJS/qrcode

The **`WinterJS.qrcode`** property provides QR utilities (qrcode backend, same renderer as the serve LAN code): returns terminal block art, 1..2048 bytes of input.

## Syntax

```js
WinterJS.qrcode("hi")
```

### Parameters

- `text`
  - : The text to encode.
