---
title: "WinterJS2.time"
slug: WinterJS2/time
---

The **`WinterJS2.time`** property provides clock utilities: `now` is epoch ms, `parse` reads RFC3339, `format` renders strtime (UTC default).

## Syntax

```js
WinterJS2.time.format(0, "%Y-%m-%d")
```

### Parameters

- `fmt`
  - : A strtime format string.
