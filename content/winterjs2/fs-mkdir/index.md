title: "WinterJS2.fs.mkdir"
slug: WinterJS2/fs-mkdir
---

The **`WinterJS2.fs.mkdir(path, opts?)`** method creates a directory; `opts.recursive` creates parents. Same object as global `fs.mkdir`.

## Syntax

```js
await WinterJS2.fs.mkdir(path, opts?)
```

### Parameters

- `opts`
  - : Optional `{ recursive }`.
