The **`Deno`** global object is the Deno runtime namespace for Deno-specific,
non-standard APIs (file system, processes, networking, testing). It is frozen.

## Syntax

```js
Deno.version
await Deno.readTextFile("hello.txt")
```

### Parameters

- `version`
  - : Version information for the Deno CLI runtime environment.
