title: "WinterJS.fs.remove"
slug: WinterJS/fs-remove
---

The **`WinterJS.fs.remove(path, opts?)`** method removes a file or directory; directories need `opts.recursive`. Same object as global `fs.remove`.

## Syntax

```js
await WinterJS.fs.remove(path, opts?)
```

### Parameters

- `opts`
  - : Optional `{ recursive }`.
