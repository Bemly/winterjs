title: "WinterJS2.qrcode"
slug: WinterJS2/qrcode
---

The **`WinterJS2.qrcode`** property provides QR utilities (same renderer as the server LAN page): returns terminal block art, 1..2048 bytes of input.

## Syntax

```js
WinterJS2.qrcode("hi")
```

### Parameters

- `text`
  - : The text to encode.
