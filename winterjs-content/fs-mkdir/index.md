---
title: "WinterJS.fs.mkdir"
slug: WinterJS/fs-mkdir
---

The **`WinterJS.fs.mkdir(path, opts?)`** method creates a directory; `opts.recursive` creates parents. Same object as global `fs.mkdir`.

## Syntax

```js
await WinterJS.fs.mkdir(path, opts?)
```

### Parameters

- `opts`
  - : Optional `{ recursive }`.
