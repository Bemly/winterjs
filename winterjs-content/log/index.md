title: "WinterJS.log"
slug: WinterJS/log
---

The **`WinterJS.log`** property provides structured log into the tracing pipeline (`WINTERJS_LOG` filter/file apply): `debug/info/warn/error`, 4k chars max.

## Syntax

```js
WinterJS.log.info("hello")
```

### Parameters

- `msg`
  - : The message.
