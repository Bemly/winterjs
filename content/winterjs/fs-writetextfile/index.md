The **`WinterJS.fs.writeTextFile(path, text)`** method writes a UTF-8 string to a file. Same object as global `fs.writeTextFile`.

## Syntax

```js
await WinterJS.fs.writeTextFile(path, text)
```

### Parameters

- `text`
  - : The string to write.
