---
title: "WinterJS.version"
slug: WinterJS/version
---

The **`WinterJS.version`** property holds the current winterjs version string
(CalVer `YY.MM.DD`, e.g. `"26.9.27"`). Assigning a string overrides it for the
rest of the session.

## Syntax

```js
WinterJS.version
```

### Parameters

- `version`
  - : The version string.
