title: "WinterJS.fs.writeFile"
slug: WinterJS/fs-writeFile
---

The **`WinterJS.fs.writeFile(path, data)`** method writes data to a file, creating or truncating it. Same object as global `fs.writeFile`.

## Syntax

```js
await WinterJS.fs.writeFile(path, data)
```

### Parameters

- `data`
  - : A string, `Uint8Array`, or `ArrayBuffer`.
