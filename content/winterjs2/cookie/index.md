---
title: "WinterJS2.cookie"
slug: WinterJS2/cookie
---

The **`WinterJS2.cookie`** property provides cookie codec: `parse` reads the first pair, `serialize` builds a Set-Cookie value.

## Syntax

```js
WinterJS2.cookie.serialize("a", "1", { path: "/" })
```

### Parameters

- `name`
  - : The cookie name.
