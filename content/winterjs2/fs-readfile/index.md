slug: WinterJS2/fs-readFile
---

The **`WinterJS2.fs.readFile(path)`** method reads the entire contents of a file as a `Uint8Array`. Same object as global `fs.readFile`.

## Syntax

```js
await WinterJS2.fs.readFile(path)
```

### Parameters

- `path`
  - : A non-empty string path.
