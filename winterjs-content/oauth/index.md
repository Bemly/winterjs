The **`WinterJS.oauth`** property provides OAuth2 helpers (oauth2 wheel for URL+PKCE, token HTTP rides fetch): `authorizeUrl`, `pkce`, `exchangeCode`, `refreshToken`.

## Syntax

```js
WinterJS.oauth.pkce()
```

### Parameters

- `options`
  - : See `authorizeUrl`/`exchangeCode` shapes.
